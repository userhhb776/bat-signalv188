# Bat Signalv188

Quero criar um aplicativo pessoal parecido com a https://reportana.com/pt aonde posso criar agentes de ia para suporte e recuperação de vendas (conectado ao meu gateway)... posso por também conectar eles ao telegram ou WhatsApp para atenderem e mandarem mensagem... pode mandar sms, e-mail marketing e entre outros... para enviar pelo WhatsApp eu usaria o render.com e para o telegram eu conectaria um bot por token... ela também teria Carrinhos Abandonados: Disparo automático de mensagens para clientes que iniciaram uma compra mas não a finalizaram. Recuperação de Vendas, Criação de Chatbots e entre outros. Os gateways serão configurados diretamente na plataforma, assim como a reportana original faz. Para o envio de mensagens usaremos o render.com e para a ia usaremos a api do ollama ou de outras ias.
